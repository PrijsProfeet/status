Incidenten

Geopend na twee opeenvolgende mislukte checks (~10 min), zodat een enkele timeout geen "incident" is. Dekt alleen wat deze probe zelf ziet (bereikbaarheid van de site en de API) — niet elk intern alarm.

    Maandelijkse beschikbaarheid (Business SLA)

    Dit is de contractuele meting — een externe probe op /api/v1/ready, elke 30s, met releasevensters uitgesloten. Zie de API-voorwaarden (art. 10).

    Checks lopen elke paar minuten vanaf GitHub Actions — buiten het prijsprofeet.nl-netwerk, zodat een storing daar deze pagina niet meesleurt. Elke balk is één UTC-dag over de laatste 31 dagen.
